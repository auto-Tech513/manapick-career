## 本番で確認した事実（2026-07-20）

- ニュース詳細ページでAdSense本体スクリプトはHTTP 200で読み込まれ、ブラウザコンソールエラーは0件だった
- 手動枠 `8041327454` は表示幅758px・リクエスト面90pxの有効な広告リクエストをGoogleへ送り、Googleのレスポンス自体はHTTP 200だった
- 最初の確認ではGoogleが同じ手動枠へ `data-ad-status="unfilled"` を付与し、実クリエイティブではなくmanapi商店の自社案内が表示された
- その後の同日本番確認では同じpublisher・slotが `data-ad-status="filled"` となり、広告クリエイティブの配信を1回確認した。確認時の外側の広告要素は758×280pxで、ブラウザログは0件だった
- `https://career.manapick.app/ads.txt` はpublisher `pub-4108900975353940` を返し、CSPは当該広告リクエストを遮断していなかった

このため、2026-07-20の「広告が見えない」確認回は、スクリプト未設置、CSP違反、ads.txt欠落、広告枠のゼロ幅ではなく、当該リクエストが未充填だった。一方、別の確認回では同じ枠が充填されたため、サイト実装が配信を妨げ続けている状態でもない。充填はリクエストごとに変わり、サイト側から広告需要やGoogleの配信判断を強制できない。

## レスポンシブ表示検証

2026-07-20の静的ビルドを実ブラウザで確認し、`document.documentElement.scrollWidth` は375 / 390 / 768 / 1280pxの全幅でviewportと一致した。広告枠による横あふれは0pxだった。ただし、これは全幅で充填済みクリエイティブを表示した試験ではない。充填を確認できたのは1回だけであり、充填済み実広告を伴う375 / 390 / 768 / 1024 / 1280 / 1440 / 1920pxの全幅確認は未確認である。

## 2026-11-19 変更（オーナー判断 14:38「デザインを壊す広告だけを外し、収益は手動枠の追加・移動で補う」）

- `components/AdSenseScript.tsx` の広告スクリプトに `data-overlays="bottom"`（公式ヘルプ answer/7478225）を付け、アンカー広告を画面の下端だけに出すようにした（SP の上端アンカー 427px がヘッダーと画面の約半分を覆っていたため）。アンカー広告そのものは残す
- 広告インテント（札・チップ・語句の下線）を出さない範囲として、駅レール・ヘッダー・メニュー（ドロワー）・トップの検索欄・下部ナビ・乗り換えシート・フッター最下段のコンテナに `google-anno-skip`（公式ヘルプ answer/13844047）を付けた。本文の広告インテントは残す
- 手動枠を追加：本家の汎用レスポンシブユニット `1438236565` を、5節以上のニュース・ガイド記事の最後の節の後（既存の第2節の後の枠との間に3節以上。全165記事で枠の間隔は画面1枚分より広い）と、ホームの入口案内（7つの入口）の後に1枠ずつ。`AdSlot` の `fold` で、配信されるまで高さを取らず、未配信なら枠ごと畳む（自社案内は出さない）
- PC で暗いフッターの下に AdSense の body の下余白（154px）が明るい帯として見えていたため、余白と同じ太さの暗い下線をフッターに付けて負の下余白で引き戻した（`--ad-anchor-bottom-pad`）
- 要確認：本番ホスト名のままローカルのビルドで確かめた範囲（2026-11-19、SP 360〜430px の WebKit と Android の Chrome）では、`data-overlays="bottom"` を付けても上端のアンカー広告（305〜427px）が出続けた。useEffect での動的な挿入に加え、検証用に head の静的タグ・旧式の `overlays: {bottom: true}` も試したが同じだった。上端のアンカーが出ている間は、従来どおり `--ad-anchor-top` でヘッダー・メニュー・乗り換えシートをずらしている
- 2026-11-19（追補）：SP では上端のアンカーがスクロール後に余白なしで重なって出たあと、上へ戻ったときなどに AdSense が body に上余白（390px 幅で 355〜452px）を付け、iPhone の Safari 相当で本文が一度に下へずれていた。`components/AdSenseScript.tsx` で、上余白が変わったときに本文が画面の中で動いた分だけスクロール位置を戻す（ブラウザ・AdSense 自身が補正した場合は二重に補正しない）
